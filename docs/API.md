# API

Базовый URL в Docker: `http://localhost:8000`. Веб-кабинет доступен на `/`,
Swagger UI — на `/docs`. При локальном запуске самого API без Nginx стандартный адрес
ASP.NET Core — `http://localhost:5000`.

Интерактивная схема ASP.NET Core доступна в Swagger UI по `/docs`. Ниже —
короткая интеграционная инструкция.

## Аутентификация

Все методы, кроме регистрации и health-check, принимают один из заголовков:

```http
X-API-Key: rb_live_...
```

или:

```http
Authorization: Bearer rb_live_...
```

Административное пополнение использует отдельный `X-Admin-Token` из `.env`.

## Методы

### `POST /v1/accounts/register`

Создаёт организацию, начисляет ей 1000 ₽ и возвращает первый API-ключ.

```json
{
  "name": "ООО Ромашка",
  "email": "api@example.ru"
}
```

### `POST /v1/remove-background`

Принимает `multipart/form-data`, поле `image`. Поддерживаются JPEG, PNG и WebP до
15 MiB и до 40 млн пикселей. Успешный ответ имеет `Content-Type: image/png` и содержит
готовый файл. Списание выполняется только после получения результата от модели.

Значимые заголовки ответа:

- `X-Request-ID` — идентификатор для диагностики;
- `X-Charged-Rub` — списанная сумма;
- `X-Balance-Rub` — остаток;
- `X-Image-Width`, `X-Image-Height` — размер оригинала.

### `GET /v1/balance`

Возвращает остаток, успешный объём текущего месяца, цену следующей обработки и все
тарифные ступени.

### `GET /v1/usage?limit=50&offset=0`

Возвращает агрегаты и журнал обработок. Неуспешные операции имеют цену `0.00`.

### `GET /v1/api-keys`

Возвращает ключи без секретной части: имя, префикс, время создания/использования и
отзыва.

### `POST /v1/api-keys`

```json
{"name": "mobile-app"}
```

Секрет нового ключа возвращается только один раз.

### `DELETE /v1/api-keys/{key_id}`

Безвозвратно отзывает ключ. История использования сохраняется.

### `POST /v1/admin/accounts/{account_id}/top-up`

Временная замена эквайрингу для пилота. Требует `X-Admin-Token`.

```json
{
  "amount_rub": "2000.00",
  "description": "Оплата по счёту №42"
}
```

## Ошибки

Ошибки возвращаются единообразно:

```json
{
  "error": {
    "code": "insufficient_funds",
    "message": "Недостаточно средств на балансе",
    "request_id": "1b8d..."
  }
}
```

Основные статусы: `401` — ключ, `402` — баланс, `413` — размер, `415` — формат,
`422` — повреждённое изображение, `429` — очередь обработки занята, `503` — модель
прогревается или временно не обработала файл. Для временных состояний сервер возвращает
`Retry-After`.
